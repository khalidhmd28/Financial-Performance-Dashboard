## Financial-Performance-Dashboard
An interactive Power BI dashboard that tracks revenue, expenses, profitability and budget variance across two fiscal years (FY2024 and FY2025). It is built on a simulated general-ledger (GL) dataset and modelled as a star schema, with DAX measures for margins, year-over-year (YoY) growth and budget variance.
